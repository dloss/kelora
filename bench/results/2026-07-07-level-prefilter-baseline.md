# Level pre-filter — baseline measurement

Recorded **before** implementing the optimization, per the spec's
measurement-first order. The baseline binary is frozen at
`bench/bin/kelora-baseline` so the before/after comparison uses the exact
pre-change build.

## Environment

- CPU: Intel(R) Xeon(R) @ 2.80GHz, 4 cores
- OS: Ubuntu 24.04.4 LTS, Linux 6.18.5 x86_64
- rustc 1.86.0, release profile (`cargo build --release`)
- hyperfine 1.18.0 (`--warmup 3 --min-runs 10`)
- Corpora: 1,000,000 lines each, generated by `bench/gen_corpus.py` (seeded)

## Baseline binary

- Commit: `b3072cfcc591da5c1a833d12945f2ce020d659e1` (branch base, pre-change)
